⚠️ Vulnerability 4: Broken Access Control (Client-Side Check)

The developer checked authorization using client-side JavaScript that inspects the URL query parameter ?role=admin! Because the check happens in the browser instead of an authenticated server-side session, anyone can bypass this barrier simply by providing the parameter.
